선행 조건

App Signing 등록

AAB를 올리려면 App Signing by Google Play 등록이 먼저다. 이때 기존 키를 앱 서명 키로 직접 올려야 인증서 지문이 유지된다.

  1. Play Console에서 등록 시작 앱 무결성 → 앱 서명 에서 “Java 키 저장소에서 키 내보내기 및 업로드”를 선택한다.
  2. pepk.jar 내려받기 Console이 pepk.jar와 암호화 공개키를 함께 제공한다.
  3. 기존 키 추출·암호화 오른쪽 명령으로 output.zip을 만든다.
  4. output.zip 업로드 업로드 키는 같은 키를 그대로 지정할 수 있어 빌드 스크립트를 고치지 않아도 된다. 
# 기존 keystore를 앱 서명 키로 등록
java -jar pepk.jar \
  --keystore=path/to/upload-key.jks \
  --alias=<your-key-alias> \
  --output=output.zip \
  --include-cert \
  --rsa-aes-encryption \
  --encryption-key-path=encryption_public_key.pem
주의 — Google이 새 키를 생성하게 두면 인증서 지문이 바뀌어, 지문에 묶인 외부 SDK를 모두 재등록해야 한다. 앱 서명 등록은 되돌릴 수 없으므로 기존 키 업로드를 먼저 확인한다.
